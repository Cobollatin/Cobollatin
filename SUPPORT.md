# Getting Support

Thank you for visiting my personal portfolio and website! If you have any questions, encounter a problem, have a suggestion, or want to contribute a blog post, here's how to get in touch.

## Contributing Blog Posts

**I welcome guest blog posts!** If you'd like to write content for my website, please see the [Contributing Guidelines](CONTRIBUTING.md) for detailed information on how to submit blog posts via pull requests.

## Reporting Issues or Asking Questions

Whether you've found a bug, have a question about something on the site, or want to suggest an improvement, please feel free to open an issue on GitHub.

1.  **Check Existing Issues**: Before creating a new issue, please take a moment to see if a similar topic has already been discussed.
2.  **Create a New Issue**:
    - Go to the [Issues tab](../../issues) of this repository.
    - Click on "New Issue".
    - Please use the available templates if your issue is a bug report or a feature suggestion:
      - [Report a Bug](../../issues/new?template=bug_report.md)
      - [Suggest an Enhancement](../../issues/new?template=feature_request.md)
    - For general questions, you can open a regular issue.
    - Provide a clear title and a detailed description. The more information you provide, the easier it will be for me to understand and address your query or feedback.

## Project Status

This is a personal project. I handle updates, address issues, respond to questions, and review blog post contributions as my time permits. I appreciate your understanding and patience.

Thank you for your interest!
