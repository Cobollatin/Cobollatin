このサイトのブログは **Astro Content Collections** で管理されています。記事は `src/content/blog/` に置き、`src/pages/blog/`（デフォルト言語）と `src/pages/[lang]/blog/`（ローカライズされたルート）でレンダリングされます。

## 1) 新しい記事を作る（推奨: スキャフォールド用スクリプト）

対応している各ロケール用のファイルをまとめて作るには、次を実行します:

```bash
bun run new:post <slug> "任意のタイトル"
```

これにより `src/content/blog/<slug>/` が作成され、ロケールごとに `.mdx` ファイルが生成されます（`src/i18n/locales.ts` を参照）。

手動で作る場合は、記事の slug 名のフォルダ（この名前が URL の slug になります）を作成し、その中に `ja.mdx` を追加します（必要なら他言語も追加）:

- ファイル: `src/content/blog/my-new-post/ja.mdx`
- URL（日本語）: `/ja/blog/my-new-post/`

## 2) フロントマター（必須フィールド）

各記事は `src/content.config.ts` の blog コレクションのスキーマに合う frontmatter が必要です。

最小の必須 frontmatter:

```yaml
---
title: '新しい記事'
description: '一覧やプレビュー、SEO に使われる 1 文の要約。'
pubDate: '2026-02-02'
lang: 'ja'
---
```

任意（推奨）フィールド:

- `heroImage`: 画像パス（通常 `public/` 配下）
- `keywords`: フィルター/検索に使う文字列配列
- `updatedDate`: 「最終更新 …」の行を表示

すべて含めた例:

```yaml
---
title: '新しい記事'
description: '一覧やプレビュー、SEO に使われる 1 文の要約。'
pubDate: '2026-02-02'
updatedDate: '2026-02-10'
heroImage: '/blog-placeholder-1.jpg'
keywords: ['astro', 'content collections', 'writing']
lang: 'ja'
---
```

## 3) 本文を書く

Markdown（または MDX）で書けます。見出しには `astro.config.ts` の rehype 設定により自動でアンカーリンクが付与されます。

## 4) i18n: 同じ記事の翻訳を追加する

このプロジェクトのロケールは `src/i18n/locales.ts` で定義されています:

- `en`（デフォルト）
- `es`, `zh`, `ja`, `ru`

### ブログ翻訳のグルーピング方法

翻訳は **translation key** によってグループ化されます。これは `src/content/blog/` 内の最初のパスセグメント（つまりフォルダ名）から導かれます。

つまり、次のように同じフォルダ名を共有するファイルは同一記事の翻訳として扱われます:

- `src/content/blog/my-new-post/en.mdx`（`lang: 'en'`）
- `src/content/blog/my-new-post/ja.mdx`（`lang: 'ja'`）

URL は次のようになります:

- 英語: `/blog/my-new-post/`
- 日本語: `/ja/blog/my-new-post/`

特定のロケールの翻訳がない場合は、デフォルトロケールの内容にフォールバックします。

### 「全ロケールのファイル」を強制する

各記事に全ロケールのファイルが揃っていることをチェックしたい場合:

```bash
bun run check:i18n
```

## 5) ローカライズされたルート（ページ生成の仕組み）

- デフォルトロケール（プレフィックスなし）: `src/pages/blog/index.astro` と `src/pages/blog/[...slug].astro`
- デフォルト以外（ロケールプレフィックスあり）: `src/pages/[lang]/blog/index.astro` と `src/pages/[lang]/blog/[...slug].astro`

ヘッダーの言語切り替えは `src/i18n/routing.ts` を使って現在のパスを選択したロケールへ書き換えます。

## 6) 簡易チェックリスト

- `src/content/blog/<slug>/<locale>.mdx` に記事ファイルを作成
- frontmatter に `title`, `description`, `pubDate`, `lang` を含める
- 任意: `keywords`, `heroImage`, `updatedDate`
- ローカル実行:
  - `bun run dev`
  - `bun run check`
